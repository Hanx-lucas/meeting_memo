# 会议纪要格式与语言

## 默认格式

用户上传模板时以其格式为准；没有模板时沿用 `assets/会议纪要模板.docx`：

- 标题居中，楷体_GB2312，11 磅，加粗与模板一致。
- 一级标题用 `一、` 等编号，楷体_GB2312，10 磅，加粗、左对齐。
- 正文楷体_GB2312，9 磅，无首行缩进，单倍行距，段后 0.5 行。
- 数字和英文用 Times New Roman。
- 保留模板或参考稿的页面设置、页眉页脚和分页属性。
- 缺少指定字体时优先使用可用的楷体兼容字体，并说明替换，不将缺字文件作为已通过检查的成品。

## 章节结构

标题为会议主题和可确认的日期，章节跟随录音中的话题先后。不强制套用固定提纲或内置模板的十个章节。可按实际内容使用 `核心判断：`、`具体情况：`、`后续展望：`、`行动事项：` 等标签；不要为了标签而拆散条件与结论，或重复一段内容。

## 书面化表达

- `就是我们可能下个月吧，先试个两个门店。` → `可能于下个月先在两家门店试点。` 日期可以从会议日期确定时再替换为具体月份。
- `收入大概一亿吧，但这个没包括海外。` → `收入约为1亿元，不含海外业务。`
- `如果原料涨价，毛利率可能就会低一点。` → `若原材料价格上涨，毛利率可能下降。` 不补造下降幅度。
- 若不同说话人的判断冲突，分别保留意见及归属，不合成为共识。责任人、承诺人和信息来源有实质意义时应保留姓名或明确角色。

避免 `交流口径称`、`会议口径称`、`交流显示`、`专家表示`、`根据会议内容` 等无具体来源的叙述。直接写事实或判断，以 `可能`、`预计`、`据称`、`尚未确认` 等体现不确定性；原文明确指出的信息来源应保留。

## 内容核对清单

- 所有实质讨论是否按原顺序出现，包括问答、补充、不同意见、案例和风险。
- 名称、机构、地点、产品、技术术语及缩写是否正确。
- 数字、范围、单位、日期、百分比与百分点、日均与总量、产能与产量等是否区分。
- 条件、否定、程度、因果、预测时间和假设是否完整。
- 待办、负责人、截止日期是否来自原材料；缺失时不补造。
- 仅删除无信息的口头赘语与重复，未丢失实质内容；数字/英文词审查只是辅助线索，不能替代逐段对照。
