# 行业研究会议纪要 Skill | Industry Research Meeting Memo

将行业交流、公司调研、专家访谈等会议材料整理为**内容完整、表述专业、格式规范的 Word 会议纪要**。支持飞书妙记 TXT、一般转写文本、MP3/M4A 录音及已有 DOCX 草稿，也适用于一般中文会议。

本项目不仅关注“把口语写通顺”，更强调**保留信息、核对关键事实、适配 Word 模板与交付前审查**。它是一套面向 AI 助手的 Skill 工作规范与辅助脚本，而不是独立的语音转写应用。

## 核心特点

| 能力 | 说明 |
| --- | --- |
| **按原始顺序整理** | 遵循录音或转写的讨论顺序，允许为连续话题添加标题，但不随意重排观点。 |
| **保留实质信息** | 保留事实、数据、单位、日期、案例、判断、预测、条件、不同意见、问答新增内容与待办；只删除无信息的语气词和重复。 |
| **专业书面化** | 改善断句、语法和口语表达，保留否定、程度、因果和不确定性，不把推测改写为事实。 |
| **关键信息核验** | 对专业术语、公司与产品名称、日期及核心数据进行交叉检查，优先使用会议当时已公开的官方材料，并核对指标口径。 |
| **自定义 Word 模板** | 优先沿用用户上传的 DOCX 模板或参考稿；未提供时使用项目内置模板。 |
| **修订与质量审查** | 支持修改已有纪要，并使用 Python 脚本辅助排查遗漏线索、异常措辞和部分格式问题。 |
| **逐页排版检查** | 可将 DOCX 渲染为 PDF 和逐页图片，辅助检查截断、重叠、缺字与空白页。 |

## 适用场景与输入输出

典型场景包括券商行业研究会议、上市公司交流、专家访谈、产业链调研及其他需要准确保留原始讨论的中文会议。

**输入材料**（按实际情况提供，无需全部具备）：

- 会议转写 TXT、飞书妙记文本或其他可读取的转写材料；
- MP3/M4A 录音（需要运行环境具备录音访问及转写或回听能力）；
- 自定义 DOCX 模板或既有参考纪要（可选）；
- 需要修订、校对的已有 DOCX（可选）。

**主要交付物**：整理完成的 `.docx` 会议纪要；存在关键冲突或未核验项时，另行说明对应问题与来源。用户需要时，也可对已有纪要进行定向修订。

## 工作流程

1. **读取材料**：识别录音、转写、旧稿和模板，确认内容来源及文件格式。
2. **建立内容清单**：依原始顺序记录讨论主题、数据、条件、例子、不同意见和行动事项。
3. **整理并书面化**：去除无信息的口语赘词，逐段保留实质内容、原意与表达精度。
4. **核验重要信息**：检查名称、术语、日期、单位和关键数据；比较公开资料时先对齐统计口径与时间。
5. **生成或修订 Word**：优先使用用户模板，缺省时应用内置模板；修订旧稿时尽量保留未修改部分。
6. **质量审查**：结合脚本输出、原材料逐段对照和 DOCX 逐页渲染结果检查问题。
7. **交付文件**：输出最终 DOCX，并简要反馈重大差异、待确认事项及未完成的检查。

## 安装与使用

### 1. 获取 Skill

将仓库克隆到**你所使用的 AI 助手支持的 Skills 目录中**，并将文件夹命名为 `industry-research-meeting-memo`。例如，在目标 Skills 目录下运行：

```bash
git clone https://github.com/Hanx-lucas/meeting_memo.git industry-research-meeting-memo
```

使用前请确认助手支持读取 `SKILL.md`，且能访问该目录内的 `assets/`、`references/` 和 `scripts/`。不同助手的 Skills 安装位置和调用方式可能不同，请以各自文档为准。

### 2. 调用示例

上传会议转写或录音，可选上传 DOCX 模板，然后向支持该 Skill 的助手发送：

```text
使用 $industry-research-meeting-memo 整理这些会议材料，按录音顺序保留完整信息，将口语改为自然书面语，核对关键术语与数据，并使用我上传的模板输出 Word 纪要；没有模板时使用内置模板。
```

如需修订已有纪要：

```text
使用 $industry-research-meeting-memo 对照原始转写检查这份 Word 纪要，修正遗漏、术语及数据问题，保留原有版式，并另存修订版 DOCX。
```

### 3. 整理效果示例

**原始口语：**

> 收入大概一亿吧，但这个没包括海外。如果原料涨价，毛利率可能就会低一点。

**整理后：**

> 收入约为 1 亿元，不含海外业务。若原材料价格上涨，毛利率可能下降。

以上示例展示书面化原则，不代表对示例数字完成了外部核验：**不擅自增加精度、不改变条件与因果、不把“可能”改写成确定结论。**

## 专业信息核验原则

- **录音优先**：录音与转写冲突时，以能够辨认的原始录音为准；无法访问或听清时明确说明，不声称已核听。
- **先对齐口径**：核对主体、期间、单位、币种、统计范围，以及产能与产量、预测与实际、百分比与百分点等差异。
- **优先可信来源**：优先查会议发生时已公开的公司公告、官方材料和监管文件；后续披露可用于理解，但不直接覆盖会议当时的判断。
- **区分正常舍入与重大冲突**：合理的四舍五入差异保留录音精度；重大差异、数量级错误或会改变判断的冲突需单独反馈，不能静默改写。
- **不编造**：无法确认的名称、数值、身份、时间、来源等保留不确定性或标记待核验。公开检索不代表可以上传完整的非公开录音或转写。

详细规则见 [references/verification.md](references/verification.md)。

## Word 模板与默认格式

优先提取并沿用**用户提供的 Word 模板**：包括字体字号、标题层级、页边距、段落、表格、页眉页脚与分页设置。模板用于约束版式，不用于强行改变讨论顺序，也不应把示例内容当作真实会议事实。

未提供模板时使用 [`assets/会议纪要模板.docx`](assets/会议纪要模板.docx)，默认格式包括：

| 元素 | 默认样式 |
| --- | --- |
| 主标题 | 居中，楷体_GB2312，11 磅，按模板加粗 |
| 一级标题 | `一、` 等编号，楷体_GB2312，10 磅，加粗、左对齐 |
| 正文 | 楷体_GB2312，9 磅，无首行缩进，单倍行距，段后 0.5 行 |
| 数字与英文 | Times New Roman |

缺少字体时需使用合适替代并说明。实际章节数量与标题以会议内容为准，不强制套用固定提纲。详见 [references/style-and-language.md](references/style-and-language.md)。

## 独立审查工具

本仓库包含两项辅助脚本。以下命令在仓库根目录执行，示例文件名需要替换为实际路径。

**安装 Python 依赖**（Python 3.10+）：

```bash
python -m pip install -r requirements.txt
```

### 1. 检查 DOCX 内容与格式线索

```bash
python scripts/docx_memo_audit.py --docx FINAL.docx --source PREVIOUS.docx --transcript TRANSCRIPT.txt
```

- `--docx`：待检查的 DOCX，必填。
- `--source`：可选，对照旧版 DOCX 中可能消失的数字及英文词元。
- `--transcript`：可选，从 TXT 转写中提取部分英文术语候选并提示复核。
- `--required-term "术语"`：可重复指定必须保留的关键术语。
- `--default-format`：**仅在使用内置默认格式时**启用字号及中文标题检查；用户自定义模板不要随意开启。

例如：

```bash
python scripts/docx_memo_audit.py --docx FINAL.docx --default-format --required-term "POE"
```

脚本输出 JSON 审查结果。`pass: true` **仅代表已启用的机器检查通过**，不能证明信息没有遗漏、事实无误或排版完全正确。中文语义完整性、录音顺序和数字的业务含义仍需逐段核对。

### 2. 渲染 DOCX 进行逐页检查

需要安装 **LibreOffice** 与 **Poppler（pdftoppm）**：

```bash
python scripts/render_docx_windows.py --docx FINAL.docx --output-dir QA_DIR
```

脚本在输出目录的独立子目录内生成 PDF 和逐页 PNG。它支持 Windows，也可在能找到相应工具的其他平台使用；需要时可通过 `--soffice`、`--pdftoppm` 或环境变量指定工具位置。生成图片后仍需实际检查是否存在截断、重叠、缺字或多余空白页。

运行细节见 [references/runtime-playbook.md](references/runtime-playbook.md)。

## 运行边界与注意事项

- 本项目提供的是 **Skill 指令、Word 模板和辅助审查脚本**；不包含独立语音识别模型、录音上传服务或联网检索服务。音频处理及公开资料检索依赖宿主 AI 环境支持的工具。
- 尽管支持根据原始材料核对信息，**不能保证自动完成全部内容核听、事实核验或逐页视觉检查**；受限时应明确指出未完成的部分。
- 不建议把未核实的自动生成纪要直接当作公开研究结论。对外发布前，仍应确认会议授权、信息保密要求及关键事实。
