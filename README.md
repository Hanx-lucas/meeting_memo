# Industry Research Meeting Memo

行研会议纪要 Skill：将行业交流或专家访谈的转写文本、飞书妙记 TXT、MP3/M4A 录音和已有 Word 草稿整理成可交付的 DOCX 纪要，也适用于一般中文会议。

- 支持上传自己的 Word 模板；没有模板时使用内置模板和默认格式。
- 尊重录音讨论顺序，保留事实、数据、条件、案例、不同意见和待办。
- 将口语改为自然书面语，保留原意、因果和不确定性。
- 核对关键名称、日期和数据：四舍五入差异以录音为准，重大差异反馈给用户。
- 支持旧稿修订、文字审查和逐页排版检查。

## 使用

将技能文件夹命名为 `industry-research-meeting-memo`，放入支持 SKILL.md 的助手技能目录。上传转写或录音，可选上传 DOCX 模板或旧稿，然后调用：

```text
使用 $industry-research-meeting-memo 整理这些会议材料，按录音顺序保留完整信息，使用我上传的模板输出 Word 纪要；没有模板时用内置模板。
```

录音处理和公开信息检索依赖助手环境的相应工具。独立运行审查脚本需要 Python 与 `requirements.txt` 中的依赖；渲染还需要 LibreOffice 和 Poppler。机器审查辅助发现问题，不能代替录音核听、内容对照和逐页检查。
